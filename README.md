# War of Dots

Браузерная реализация. Шаг 2: одна карта, игра запускается сразу, войсками управляет игрок.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Открыть адрес, который напечатает Vite (обычно <http://localhost:5173/>).
Меню нет — матч начинается сразу. Вы играете за синих.

## Управление

Взято из встроенного гайда оригинала.

| Действие | Ввод |
|---|---|
| Выделить юнита | ЛКМ по юниту |
| Выделить группу | ЛКМ + тянуть — рисуется петля (лассо) |
| Добавить к выделению | Shift |
| Идти в точку | с выделением — клик по земле |
| Нарисовать маршрут | с выделением — тянуть |
| Двигаться строем | Shift + тянуть |
| Сбросить приказы | C |
| Стоп | S |
| Зум | колесо |
| Сдвинуть камеру | ПКМ/СКМ + тянуть, WASD, стрелки, край экрана |
| Снять выделение | Esc |
| Туман войны вкл/выкл | F |
| Пауза | Space |

Приказ выполняется **сразу**: отпустили кнопку — войска пошли. Ничего
подтверждать не нужно.

Юнит сам ищет дорогу. Если по прямой пройти нельзя — считается маршрут в обход
(A\* по тайлам с учётом рельефа, так что брод дороже моста). Если юнит всё-таки
упёрся и перестал двигаться — он пересчитывает только текущий отрезок, а
нарисованный вами маршрут дальше остаётся как был.

## Что уже по правилам оригинала

- **Юниты.** Сплошной кружок — лёгкий, кружок с чёрным овалом — тяжёлый: больше
  HP и урона, медленнее, сильнее страдает от рельефа.
- **Две полоски над юнитом:** зелёная — здоровье, голубая — мораль. Низкие
  значения ослабляют юнита. Полоски появляются, когда есть что показывать.
- **Бой автоматический при столкновении.** Атакует тот, кто **движется** на
  врага: наносит больше урона, но и получает больше, и быстрее теряет мораль.
  Юнит в бою дрожит.
- **Контакт держит.** Пока юнита кто-то бьёт, он может только толкаться —
  насквозь не проходят. Тела твёрдые: друг в друге не стоят, а атакующий
  продавливает обороняющегося назад, так и двигается линия. Лобовой удар в
  готовый строй стоит примерно три четверти атакующих — обходите с фланга.
- **Лечение** идёт вне боя, быстрее вдали от врага, вдвое быстрее в снабжении.
- **Рельеф.** Равнина — норма. Лес и холмы — лёгким норма, тяжёлым медленно и
  слабо. Вода тормозит всех и снижает урон. Песок тормозит лёгких. Горы
  непроходимы. Города и мосты как равнина.
- **Линия фронта** — граница территорий, а не «середина между армиями». Юнит
  держит землю в нескольких своих радиусах вокруг себя, клетка достаётся тому,
  кто держит её сильнее, а ничейную клетку **никто не переписывает** — она
  остаётся за прежним хозяином. Поэтому линия идёт вплотную к войскам, едет
  вместе с наступающими, остаётся там, где её оставили, и замыкается в тугую
  петлю вокруг отрезанного юнита — петля одного размера, как глубоко он бы
  ни зашёл. Считается **только от юнитов** — точки своей земли не держат.
- **Туман войны** без памяти: вне текущего обзора всё снова темнеет. Врагов в
  тумане не видно, а рельеф, линия фронта и города видны всегда.
- **Точки** — жёлтый кружок, столица — звезда, владелец показан флажком.
  Точка переходит к тому, кто стоит на ней один, без противника рядом. Ни денег
  (экономики пока нет), ни территории: границ у точек нет, линию фронта двигают
  только войска. Всё, что даёт точка, — снабжение.
- **Снабжение и окружение.** Юнит **в снабжении**, если от него можно дойти до
  своей точки, не пересекая линию фронта. Отрезали — он перестаёт лечиться и
  начинает **терять HP** (полное здоровье сгорает примерно за 50 секунд), и в
  бою тоже: котёл обычно занят, и если бой это отменял бы, механика не сработала
  бы ни разу. Восстановили связь — снова лечится. Поэтому окружение имеет смысл:
  добивать котёл не обязательно, достаточно зайти в тыл и подождать.
  Свои отрезанные юниты обведены оранжевым пунктиром, счётчик — в левом верхнем
  углу. Стоять **на** своей точке — бонус сверху: всё вдвое быстрее.

## Чего пока нет

Экономики и производства (деньги, ползунки MAX/MIN и LIGHT/HEAVY, $200/$400),
захвата городов и условия победы, кораблей, противника-бота. Красные сейчас
стоят на месте — это нужно, чтобы проверить именно управление. Обе армии
начинают по своим берегам реки, вплотную к ней, — фронт есть с первого кадра.

## Файлы

```
src/terrain.ts    карта и её генерация
src/world.ts      состояние мира, юниты, выделение, отложенные приказы
src/sim.ts        движение, бой, мораль, лечение
src/frontline.ts  контур линии фронта
src/camera.ts     камера и зум
src/input.ts      мышь и клавиатура, приказы
src/render.ts     отрисовка, включая туман
src/main.ts       запуск
```
