# War of Dots

Шаг 1: одна карта, игра запускается сразу — без меню и без лишнего.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Vite напечатает адрес (обычно <http://localhost:5173/>) — открыть его. Игра
стартует сразу, ничего нажимать не надо.

## Что сейчас есть

- **Рельеф** — равнина, лес, холмы, горы, река с мостами. Рисуется по тайлам без
  сглаживания, поэтому границы «лесенкой», как на референсе.
- **Войска** — синие и красные. Лёгкий это сплошной кружок, тяжёлый — с чёрным
  кольцом. Ходят, дерутся, приходят подкрепления из столиц.
- **Линия фронта** — толстая чёрная кривая. Считается как контур, где влияние
  двух сторон равно, поверх сглаженного поля.
- **Туман войны** — видно только вокруг своих (синих). Врагов в тумане не видно
  вообще; линия фронта и жёлтые метки городов видны всегда.
- **Стрелки направления** — куда юнит идёт прямо сейчас.
- **Полоски HP** — над юнитами, которые ранены или в бою.

## Клавиши

| Клавиша | Действие |
|---|---|
| `F` | туман войны вкл/выкл — переключение между видом игрока и обзором целиком |
| `Пробел` | пауза |

## Файлы

```
src/terrain.ts    карта и её генерация
src/world.ts      состояние мира, войска
src/sim.ts        движение и бой
src/frontline.ts  контур линии фронта
src/render.ts     вся отрисовка, включая туман
src/main.ts       запуск
```
