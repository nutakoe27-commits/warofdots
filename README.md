# dotfront

Минималистичный браузерный варгейм точек. Только одиночная игра против ИИ-ботов:
никакого мультиплеера, бэкенда, аккаунтов и игровых движков.

Реализовано по техзаданию в [`docs/SPEC.md`](docs/SPEC.md). План по фазам —
[`docs/PLAN.md`](docs/PLAN.md), журнал архитектурных решений —
[`docs/DECISIONS.md`](docs/DECISIONS.md).

---

## Как запустить

Нужен **Node.js 20 или новее** (проверено на 22) и npm. Больше ничего:
ни базы, ни сервера, ни глобальных пакетов.

```bash
npm install      # один раз
npm run dev      # dev-сервер Vite
```

Откройте адрес, который напечатает Vite — обычно <http://localhost:5173/>.
Дальше: **Схватка → выбрать карту и сложность → Начать**.

### macOS

Ничего специфичного для macOS в проекте нет — работает и на Apple Silicon, и на
Intel. Node проще всего поставить одним из двух способов:

```bash
brew install node          # Homebrew
# либо через nvm, если нужно держать несколько версий:
brew install nvm && nvm install 22 && nvm use 22
```

Дальше как обычно:

```bash
git clone <url-репозитория> && cd warofdots
npm install
npm run dev
```

Особенности управления на маке:

- **`Cmd` работает как `Ctrl`** — `Cmd+A`, `Cmd+H`, `Cmd+L`, `Cmd+1..9` делают то
  же, что и с `Ctrl`.
- **ПКМ на трекпаде.** Путь рисуется правой кнопкой, поэтому нужен правый клик:
  двумя пальцами по трекпаду, либо `Control` + клик. Если не срабатывает —
  включите «Имитация правой кнопки» в *Системные настройки → Трекпад → Наведение
  и щелчок → Дополнительный щелчок*.
- **Зум** — колесо мыши или скролл двумя пальцами; жест pinch тоже работает.
  Браузер не масштабирует страницу: обработчик перехватывает жест.
- **Safari поддерживается** (равно как Chrome и Firefox). Кэш рельефа рисуется в
  обычный `<canvas>`, а не в `OffscreenCanvas`, поэтому старые версии Safari тоже
  запускаются.

Если нужен доступ с другого устройства в той же сети, dev-сервер уже слушает
на всех интерфейсах (`host: true`) — Vite напечатает адрес вида
`http://192.168.x.x:5173/`.

Сборка статики для раздачи с любого хостинга:

```bash
npm run build    # результат в dist/
npm run preview  # локально посмотреть собранную версию
```

`dist/` — обычные файлы, ничего серверного не требуется.

## Все команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с горячей перезагрузкой |
| `npm run build` | production-сборка в `dist/` |
| `npm run preview` | посмотреть собранную версию |

| `npm run map:png` | выгрузить карты в PNG-маски для правки в редакторе |
| `npm run format` | Prettier |

## Управление

| Действие | Ввод |
|---|---|
| Выделить юнита | ЛКМ |
| Выделить группу | ЛКМ + перетаскивание — **лассо произвольной формы** |
| Добавить к выделению | `Shift` + ЛКМ или `Shift` + лассо |
| Задать путь | ПКМ + перетаскивание — **рисуете кривую**; короткий клик ПКМ — прямая |
| Добавить путь в очередь | `Shift` + ПКМ |
| Стоп | `S` |
| Сбросить приказы | `C` |
| Выделить всех | `Ctrl+A` |
| Только тяжёлые / только лёгкие | `Ctrl+H` / `Ctrl+L` |
| Группы | `Ctrl+1..9` назначить, `1..9` выбрать |
| Пауза | `Space` |
| Скорость | `+` / `-`, либо кнопки 1× 2× 3× в HUD |
| Камера | ПКМ-драг по пустоте, СКМ-драг, `W A D X`, стрелки, край экрана, колесо — зум |
| Показать/скрыть территорию | `T` |
| Оверлей ИИ | `F3` |
| Панель отладки и баланса | `F4` |
| Меню | `Esc` |

`S` отдан «Стопу», поэтому камера вниз ходит на `X` и `↓` — в ТЗ эта клавиша
назначена дважды, подробности в [ADR-010](docs/DECISIONS.md#adr-010).

## Настройка ботов и баланса

**Профили сложности** — `src/ai/profiles.ts`. Главная ручка — `apmBudget`:
слабый бот не «играет плохо нарочно», он физически не успевает микрить армию.

| Профиль | APM | Задержка | Шум | Порог цикла | Окружения | Рельеф | Ошибки |
|---|---|---|---|---|---|---|---|
| Новобранец | 8 | 900 мс | 0.45 | 0.30 | нет | нет | 0.35 |
| Лейтенант | 20 | 550 мс | 0.30 | 0.50 | нет | да | 0.20 |
| Полковник | 45 | 300 мс | 0.18 | 0.70 | да | да | 0.10 |
| Генерал | 90 | 150 мс | 0.08 | 0.82 | да | да | 0.03 |
| Маршал | 160 | 80 мс | 0.03 | 0.85 | да | да | 0.00 |

Гандикап по экономике (+15%) возможен только у «Маршала», выключен по умолчанию
и явно подписан в меню. Никакого скрытого читерства: бот видит ровно то, что
видит игрок.

**Весь баланс** — в одном файле `src/core/balance.ts`. Часть значений можно
крутить прямо в игре по `F4`, не перезагружая страницу; правки попадают в реплей,
чтобы он оставался воспроизводимым.

**Калибровка ботов** — headless-прогоны без рендера:

```bash
npm run sim -- --map crossing --a colonel --b lieutenant --games 100
npm run sim -- --map thicket  --a general --b colonel   --games 100 --csv out.csv
npm run sim -- --map quadrant --bot general --bot colonel --bot lieutenant --bot recruit --games 40
```

Печатает винрейт с 95% доверительным интервалом, длительность матчей и счётчик
нарушений жёстких запретов (тяжёлые в лесу, юниты в воде) — по нему сразу видно
регресс.

Бенчмарк симуляции:

```bash
npm run bench -- --units 600 --ticks 1000
```

## Как устроен проект

```
src/
  core/      детерминированная симуляция: ноль DOM, ноль Math.random, ноль Date.now
  ai/        боты: восприятие → стратегия → операции → тактика, плюс экономика бота
  render/    Canvas 2D: камера, слои, миникарта
  ui/        HUD и оболочка на чистом DOM
  game/      цикл, ввод, сборка матча, реплеи
  content/   карты
tools/       headless: бенчмарк, тюнер ботов, PNG-кодек
tests/       Vitest
```

Главное свойство: **`tick(world, commands)` — единственная точка мутации мира**,
и она не читает ни часы, ни DOM. Отсюда всё остальное: реплей — это сид плюс
журнал команд, headless-прогон — тот же код без рендера, а тест на детерминизм
ловит случайное число в ядре первым же прогоном.

Порядок фаз внутри тика зафиксирован в `src/core/sim.ts` и совпадает с ТЗ §3.2.

## Как добавить карту

Положите JSON в `src/content/maps/` — он попадёт в сборку сам (`import.meta.glob`),
и появится в меню.

```jsonc
{
  "id": "my-map",
  "name": "Моя карта",
  "size": { "w": 192, "h": 192 },
  "players": 2,
  "terrainGen": {
    "seed": 12345,
    "features": [
      { "type": "fill",  "terrain": "PLAINS" },
      { "type": "blob",  "terrain": "FOREST", "x": 64, "y": 64, "radius": 18, "count": 4, "jitter": 24 },
      { "type": "river", "terrain": "WATER",  "x": 96, "y": -4, "x2": 96, "y2": 196, "width": 11, "jitter": 18 },
      { "type": "road",  "terrain": "PLAINS", "x": 70, "y": 96, "x2": 122, "y2": 96, "width": 9, "jitter": 3 }
    ]
  },
  "cities": [
    { "id": "west", "x": 28, "y": 96, "capital": true, "owner": 1, "radius": 7 },
    { "id": "east", "x": 164, "y": 96, "capital": true, "owner": 2, "radius": 7 },
    { "id": "mid",  "x": 96, "y": 40, "owner": 0, "radius": 5 }
  ],
  "startUnits": [
    { "owner": 1, "kind": "light", "count": 8, "x": 40, "y": 96, "spread": 5 },
    { "owner": 2, "kind": "light", "count": 8, "x": 152, "y": 96, "spread": 5 }
  ]
}
```

Координаты — в тайлах (1 тайл = 4 игровых единицы). Кисти рельефа: `fill`, `rect`,
`blob`, `river`, `ridge`, `road`. `road` поверх `WATER` даёт мост.

Загрузчик проверяет карту при старте и падает с внятным сообщением, если у игрока
нет столицы, город недостижим или стартовые юниты стоят в горах.

Чтобы дорисовать рельеф руками: `npm run map:png` выгрузит палитровую маску рядом
с JSON, правьте её в любом редакторе и замените `terrainGen` на
`"terrainMask": "my-map.png"`.

## Правовая рамка

Клонированы **механики** — они не охраняются авторским правом. Название, логотип,
шрифты, звуки, карты, ассеты и код оригинальной War of Dots не используются.
Всё содержимое здесь своё: рельеф генерируется процедурно, палитра и интерфейс
нарисованы с нуля, спрайтов и текстур нет вообще.
